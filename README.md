# ISO 15939 Software Quality Measurement Tool

## Group Members
* Ramazan Bağış
* Orkun Yiğit Telin

## Project Description
This project is a web-based simulation tool developed according to ISO/IEC 15939 and ISO/IEC 25010 standards.

## Technologies
* HTML5
* CSS3 (Responsive Design)
* JavaScript (ES6+)
* Chart.js (Data Visualization)

## How to Run
Simply open `index.html` in any modern web browser.
